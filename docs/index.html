Locator Pilot

A Chrome extension for writing Playwright tests faster: pick any element and get a ranked set of locators in C# or TypeScript — or paste a locator back in to find it on the page.

  • Works in open shadow roots and same-origin iframes
  • Live uniqueness checks and brittleness warnings
  • No servers, no accounts, no telemetry

Source: github.com/gaurangpb/locator-pilot
