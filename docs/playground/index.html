Locator Playground

A test page for Locator Pilot. Each section is one hard case for locator generation, with what it checks and the result the extension should give. Open the panel, pick the elements in a section, then paste the listed locators into "Find on page".

Static page, no network requests, nothing stored. Assumes the default test-id attribute (data-testid).

3. Hidden elements

Buttons hidden three ways. Playwright's getByRole skips elements outside the accessibility tree, so role locators for these should find 0.

The aria-hidden button is still drawn on screen (last one above), so you can pick it. The visibility-hidden one keeps its space but can't be clicked.

6. Shadow DOM

A button inside an open shadow root, and another two shadow roots deep. Playwright's role, text and CSS engines go through open shadow roots. Its XPath engine doesn't.

7. Same-origin iframe

A child page served from the same origin. Picks and "Find on page" should work inside it, with results shown in the top-level panel.

8. Custom-element card with a screen-reader-only radio

A role-less custom element wraps a <label> (the whole visible card) and a radio with class sr-only. The selected card gets the transient classes demo-card--selected and hydrated. Click a card to move the selection.

9. Generated and transient class names

Elements with no role, text or test id, so CSS is the only option. Their classes mix stable names with CSS-in-JS hashes and state classes.

10. Live re-render
